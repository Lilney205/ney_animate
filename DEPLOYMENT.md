# Production Deployment Guide: NEY Media Core (VPS) + NEY Animate (Vercel)

This guide takes your complete streaming infrastructure online:
1. **`ney-media-core`** running on an Ubuntu VPS (FFmpeg, MediaMTX live engine, PostgreSQL, Caddy HTTPS).
2. **`ney-animate`** running on Vercel with streaming playback wired directly to the core.

---

## Step 1: Deploy `ney-media-core` to your VPS

### 1. Requirements
* Any Ubuntu 22.04 / 24.04 VPS (Hetzner, DigitalOcean, Linode, AWS EC2, etc.).
* Recommended specs: 2+ vCPU, 4GB+ RAM, 50GB+ NVMe SSD.
* A DNS A-record pointing your subdomain (e.g. `media.yourdomain.com`) to your VPS IP address.

### 2. Run the Automated Deployment
On your VPS terminal, clone or copy `ney-media-core` and execute:

```bash
chmod +x deploy-vps.sh
sudo ./deploy-vps.sh
```

The script will automatically:
- Install Docker Engine & Compose v2.
- Configure firewall rules (SSH 22, HTTP 80, HTTPS 443, RTMP 1935).
- Issue automatic Let's Encrypt SSL certificates through Caddy.
- Generate secure database passwords, playback tokens, and service keys.
- Start PostgreSQL, database migrations, API, FFmpeg worker, and MediaMTX.

When complete, it outputs your generated service credentials:
```text
Public API & Streaming URL: https://media.yourdomain.com
NEY Animate Service Key:     <YOUR_GENERATED_KEY>
```

---

## Step 2: Deploy `ney-animate` to Vercel

### 1. Push `ney-animate` to GitHub / GitLab
Make sure your changes are pushed to your git repository.

### 2. Import into Vercel
1. Log in to [vercel.com](https://vercel.com) and click **"Add New Project"**.
2. Select your `ney-animate` repository.
3. In the **Environment Variables** section, configure the following:

| Variable | Value | Description |
|---|---|---|
| `DATABASE_URL` | `postgresql://...` | Connection string for your app's PostgreSQL database (e.g. Neon, Supabase, or VPS). |
| `NEXT_PUBLIC_APP_URL` | `https://your-site.vercel.app` | Your frontend production URL. |
| `STUDIO_BOOTSTRAP_KEY` | `your-admin-key` | Secret key for studio API access. |
| `NEY_MEDIA_CORE_URL` | `https://media.yourdomain.com` | Internal API route target for your VPS Media Core. |
| `NEXT_PUBLIC_MEDIA_CORE_URL` | `https://media.yourdomain.com` | Public URL for browser player stream URLs. |
| `NEY_MEDIA_CORE_SERVICE_KEY` | `<YOUR_GENERATED_KEY>` | Bearer key generated by `deploy-vps.sh`. |

4. Click **Deploy**.

---

## Step 3: Upload a Film & Verify Playback

### Upload a film through your Studio API
From PowerShell or cURL, upload a movie directly to your streaming platform:

```powershell
$adminKey = "your-admin-key"
$appUrl = "https://your-site.vercel.app"

# 1. Request upload URL
$upload = Invoke-RestMethod -Method Post -Uri "$appUrl/api/studio/videos/direct-upload" `
  -Headers @{ "x-admin-key" = $adminKey } `
  -ContentType "application/json" `
  -Body '{"title": "Skyline Harbor", "filmSlug": "skyline-harbor", "kind": "feature"}'

# 2. Upload video bytes directly to Media Core
Invoke-RestMethod -Method Put -Uri $upload.upload.uploadUrl `
  -ContentType "video/mp4" `
  -InFile ".\your-movie.mp4"
```

### Watch the Film
1. Open your site on `https://your-site.vercel.app/films/skyline-harbor`.
2. Click **"Watch now"**.
3. The interactive player requests an authorized short-lived token from Media Core and begins adaptive-bitrate HLS streaming.
